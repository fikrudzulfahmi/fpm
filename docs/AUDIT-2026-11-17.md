# Audit bug & keamanan — 17 November 2026

Ruang lingkup: seluruh route web (`routes/web.php`), controller publik/sekolah/panitia,
middleware, service pendaftaran, unggahan berkas, serta halaman React.

Status verifikasi:

- `php -l` bersih untuk semua berkas PHP yang diubah.
- `npm run build` sukses (Vite 8, 604 modul).
- Render server-side 7 skenario halaman publik/klaim/masuk tanpa error.
- Tata letak diukur di 1440/1024/820/390 px: tidak ada overflow horizontal.
- `php artisan test` **belum** dijalankan lokal: launcher composer di mesin ini rusak
  dan `composer.lock` mensyaratkan PHP ≥ 8.3 (lokal 8.2.12). Uji backend perlu
  dijalankan di staging/CI.

## Temuan yang sudah diperbaiki

| # | Tingkat | Temuan | Perbaikan |
|---|---------|--------|-----------|
| 1 | 🔴 Tinggi | `POST /login` tanpa pembatasan percobaan — kata sandi bisa ditebak tanpa henti | `RateLimiter` 5 percobaan/akun+IP dan 25/IP per menit, `throttle:10,1`, pesan sisa waktu tunggu (`AuthController`) |
| 2 | 🔴 Tinggi | Nama berkas unggahan menentukan ekstensi yang disimpan (`getClientOriginalExtension`) pada logo event dan latar sertifikat → gambar bernama `x.php` tersimpan sebagai PHP di `public/uploads` (jalur eksekusi kode) | Ekstensi diturunkan dari MIME hasil validasi `image`; `svg` dikeluarkan dari daftar mime |
| 3 | 🟠 Sedang | Akun yang dinonaktifkan tetap bisa masuk (login & middleware sekolah tidak memeriksa `is_active`) | Login menolak akun nonaktif + `EnsureSchool` memeriksa `is_active` |
| 4 | 🟠 Sedang | `/api/nisn-check` mengembalikan nama lengkap siswa **sekolah lain** (enumerasi NISN → PII) | Nama disamarkan menjadi "Peserta sekolah lain" + flag `same_school`; UI pendaftaran menyesuaikan |
| 5 | 🟠 Sedang | ID pendaftaran dari event lama masih bisa dibuka/disetujui/ditolak panitia lewat URL langsung | `ensureCurrentEvent()` pada `show/approve/reject/reverifyAi` |
| 6 | 🟠 Sedang | Detail cabang lomba event lain/lama dapat dibuka publik lewat slug | `show()` menolak (404) bila `event_id` bukan event aktif |
| 7 | 🟠 Sedang | Tidak ada header keamanan dasar | Middleware `SecurityHeaders`: `X-Content-Type-Options`, `X-Frame-Options`, `Referrer-Policy`, `Permissions-Policy`, COOP, HSTS (https) |
| 8 | 🟡 Rendah | Pemeriksaan NISN bisa dipanggil berulang tanpa batas | `throttle:60,1` |
| 9 | 🟡 Rendah | Landing/lomba menjalankan 3 query hitung kuota per cabang (N+1) | Satu query agregat untuk semua cabang |
